# Phase 8 – Project Demonstration

Recommended demo sequence for the required screen-recorded presentation:

1. Introduce FitBuddy and its purpose.
2. Show the project structure in VS Code.
3. Start the FastAPI server.
4. Open the home page.
5. Enter sample user data and generate the plan.
6. Walk through the seven day cards and nutrition tip.
7. Submit feedback and show the updated plan.
8. Open the authenticated admin dashboard and show stored original/updated plans.
9. Open `/docs` and show the API endpoints.
10. Close with benefits, limitations and future enhancements.

Use the supplied reference video for the intended narration/visual flow.
