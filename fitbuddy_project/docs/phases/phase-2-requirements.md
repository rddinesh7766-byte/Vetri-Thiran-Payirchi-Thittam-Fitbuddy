# Phase 2 – Requirement Analysis

## Functional requirements
1. Collect name, user ID, age, weight, goal and intensity.
2. Generate exactly 7 days.
3. Include warm-up, main workout, cooldown/recovery.
4. Generate a concise nutrition/recovery tip.
5. Accept feedback and update the plan.
6. Persist users and original/updated plans.
7. Provide an admin view and delete operation.
8. Expose JSON API endpoints.

## Non-functional requirements
- Responsive UI.
- FastAPI ASGI server.
- SQLite persistence.
- Secrets stored in environment variables.
- Automated tests.
- Safe general-wellness prompting.
