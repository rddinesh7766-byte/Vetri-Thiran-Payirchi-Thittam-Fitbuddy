# Phase 1 – Brainstorming & Ideation

## Problem
Users often need a simple starting point for goal-based exercise planning.

## Proposed solution
FitBuddy accepts a small fitness profile and uses a generative AI model to create a structured 7-day plan plus a nutrition/recovery tip.

## Key scenarios
- New user generates a plan from goal and intensity.
- User gives feedback and receives a revised plan.
- Coach/admin reviews stored plans.

## Reference
The supplied SmartBridge document identifies FitBuddy as an AI fitness-plan generator using Gemini, FastAPI, Jinja2 and SQLite. The supplied YouTube video is the visual/process reference.
